# Go Web Application with PostgreSQL, Docker & Clean Architecture

Простой и масштабируемый бэкенд на Go с регистрацией пользователей, хэшированием паролей и чистой слоистой архитектурой (Layered Architecture с Dependency Injection). Проект полностью контейнеризирован.

---

## Технологический стек

- **Язык:** Go (net/http, database/sql, text/template)
- **База данных:** PostgreSQL 15
- **Безопасность:** golang.org/x/crypto/bcrypt
- **Инфраструктура:** Docker, Docker Compose

---

## Архитектура проекта

Проект организован по принципам чистой архитектуры со строгим разделением ответственности:
- **`delivery/http`** — HTTP-слой (хендлеры, роутинг, рендер шаблонов, обработка ошибок UI).
- **`service`** — Слой бизнес-логики (проверки, хэширование паролей).
- **`repository`** — Слой работы с данными (SQL-запросы, маппинг ошибок БД).
- **`database`** — Подключение к PostgreSQL и инициализация.
- **`models`** — Структуры данных (доменные модели).
- **`config`** — Конфигурация приложения.

## Особенности реализации

* **Чистая архитектура:** Четкое разделение на транспорт (`delivery`), бизнес-логику (`service`) и работу с хранилищем (`repository`).
* **Dependency Injection:** Все зависимости пробрасываются через конструкторы в `main.go`.
* **Безопасность:** Пароли надежно хэшируются с помощью `bcrypt`.
* **Интеллектуальная обработка ошибок:** Ошибки базы данных (например, дублирование email) перехватываются и преобразуются в понятные для пользователя сообщения.
* **Изоляция и персистентность:** Приложение и база запущены в контейнерах, данные сохраняются через Docker Volume.

## Запуск приложения

1. Соберите и запустите проект через Docker Compose:
```bash
docker compose up --build

```


2. Откройте страницу регистрации в браузере:
[http://localhost:8080/register](http://localhost:8080/register)

---

## Проверка данных в базе

Подключитесь к базе данных через запущенный контейнер:

```bash
docker compose exec db psql -U root -d mydb

```

После этого можно посмотреть зарегистрированных пользователей:

```sql
SELECT * FROM users;

```
