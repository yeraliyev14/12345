# Go Web Application with PostgreSQL and Docker

Простой бэкенд на Go с функционалом регистрации пользователей, хэшированием паролей и персистентным хранилищем данных. Проект собран с соблюдением каноничной структуры Go-приложений и полностью контейнеризован.

---

## Технологический стек

- Язык: Go (стандартные библиотеки net/http, database/sql, text/template)
- База данных: PostgreSQL 15
- Безопасность: golang.org/x/crypto/bcrypt
- Инфраструктура: Docker, Docker Compose

---

## Особенности реализации

- Безопасное хранение паролей с использованием алгоритма bcrypt.
- Разделение приложения и базы данных по изолированным контейнерам.
- Автоматическое накатывание SQL-миграций при первом старте PostgreSQL.
- Хранение данных базы в Docker Volume, благодаря чему они сохраняются при перезапуске.

---

## Структура проекта

.
├── cmd/app/main.go                 # Точка входа в приложение
├── internal/
│   ├── db/db.go                    # Подключение и работа с PostgreSQL
│   └── handlers/auth.go            # Логика регистрации и хэширования
├── migrations/
│   └── 000001_create_user_table.up.sql  # SQL-скрипт создания таблицы
├── web/templates/register.html     # HTML-шаблон страницы регистрации
├── Dockerfile                      # Многоэтапная сборка Go-приложения
└── docker-compose.yml              # Конфигурация контейнеров и сетей

---

## Запуск приложения

1. Запустите сборку и контейнеры:

   docker compose up --build

2. Откройте в браузере страницу регистрации:

   http://localhost:8080/register

---

## Проверка данных в базе

Чтобы просмотреть список зарегистрированных пользователей и убедиться, что пароли хэшируются, выполните команду в терминале:

docker exec -it postgres_db psql -U root -d mydb -c "SELECT id, email, password_hash, created_at FROM users;"

---

## Остановка и управление

- Остановка контейнеров:

  docker compose down

- Остановка с удалением тома базы данных (полный сброс данных):

  docker compose down -v
